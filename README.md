# Mohammed Rasheef — Portfolio

A lightweight, editable static website recreation based on the publicly visible portfolio at `rasheefsirajportfolio.lovable.app`. It has no external libraries, fonts, or build dependencies.

## Files

- `index.html` — all page copy, section structure, links, and project descriptions.
- `styles.css` — colors, typography, spacing, and responsive layouts.
- `script.js` — mobile navigation behavior.
- `portrait.png` — local copy of the portrait shown on the reference site.

## Edit it

Open the folder in a code editor such as Visual Studio Code. Edit the text and links in `index.html`; change colors and layout in `styles.css`. Keep `portrait.png` beside `index.html` unless you update its image path.

The website uses no build step or package installation. Open `index.html` in a browser to preview it.

## Publish with GitHub Pages

1. Create a public repository on GitHub.
2. Upload all four files (`index.html`, `styles.css`, `script.js`, `portrait.png`) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published site address in the Pages settings. Updates to the repository will update the website.

You can also import this folder into Vercel as a static site; no framework preset or build command is needed.

Project names, descriptions, role history, skills, social links, and the current Technocity.lk role reflect the visible reference website or the supplied conversation. Project links and additional claims were not added where the reference page did not show them.
